# Использование полей

В текстах кнопок можно использовать подстановки в формате `{{название_поля}}`.

Когда бот создаёт заявку, задачу, автоматическое сообщение или системный текст, система заменяет такие поля на реальные данные клиента, Telegram-контакта, заявки или сотрудника.

Пример:

`"РОП {{contact_full_name}} открыл чат с тех. поддержкой"`

Если в карточке клиента заполнено `Фамилия: Иванов` и `Имя: Иван`, то в заявке будет создан системный текст:

`РОП Иванов Иван открыл чат с тех. поддержкой`

Если поле пустое или данных нет, система должна подставлять `не указано`.

## Поля клиента

{{contact_full_name}} - Полное имя из карточки клиента: Фамилия + Имя.

{{contact_first_name}} - Имя из карточки клиента.

{{contact_last_name}} - Фамилия из карточки клиента.

{{verification_status}} - Статус верификации клиента.

{{destination}} - Значение поля `Куда..?` из карточки клиента.

{{department}} - Отдел клиента, если он рассчитан или заполнен в карточке.

{{sand_owner}} - Выбранный песок, если клиент относится к стажировке/песку.

{{sales_group}} - Выбранная группа отдела продаж.

{{location_type}} - Расположение клиента: офисный или удалённый.

{{anydesk}} - Anydesk клиента, если указан.

{{internal_number}} - Внутренний номер клиента.

{{bitrix_login}} - Логин Bitrix.

{{bitrix_password}} - Пароль Bitrix.

{{bitrix_id}} - ID пользователя в Bitrix.

## Поля Telegram

{{telegram_username}} - Username клиента в Telegram. Если username есть, лучше отображать его с `@`.

{{telegram_display_name}} - Имя клиента так, как оно отображается в Telegram.

{{telegram_user_id}} - ID пользователя Telegram.

{{telegram_chat_id}} - ID чата Telegram.

## Поля заявки или задачи

{{ticket_subject}} - Тема обращения. Обычно это название кнопки, по которой клиент создал заявку или задачу.

{{ticket_created_at}} - Дата и время создания заявки или задачи в человекочитаемом виде.

{{ticket_id}} - Внутренний ID заявки в helpdesk.

{{client_message}} - Первое сообщение клиента в задаче или заявке, если оно уже есть.

## Поля сотрудника поддержки

Эти поля используются там, где уже известен назначенный сотрудник.

{{agent_full_name}} - Имя назначенного сотрудника поддержки.
